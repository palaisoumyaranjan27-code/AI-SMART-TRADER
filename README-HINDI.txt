AI SMART TRADER — Android starter project

यह शुरुआती Android ऐप एक PAPER TRADING / सीखने वाला simulator है।

अभी उपलब्ध:
- NSE/BSE watchlist के नमूना शेयर
- नमूना price chart
- बहुत सरल rule-based signal label
- Demo BUY / Demo SELL
- ₹1,00,000 virtual demo cash और holdings

महत्वपूर्ण सीमाएँ:
- कीमतें fixed sample data हैं; live market data नहीं।
- Signal कोई भरोसेमंद prediction या investment advice नहीं है।
- कोई broker connection या real order placement नहीं है।
- इस प्रोजेक्ट को real-money auto trading के लिए उपयोग न करें।

Android Studio में खोलना:
1. ZIP extract करें।
2. Android Studio खोलें।
3. Open चुनें और AI_SMART_TRADER folder चुनें।
4. Gradle sync पूरा होने दें।
5. Android SDK 35 install/available रखें।
6. Emulator या अपने Android phone पर Run दबाएँ।
7. APK बनाने के लिए Build > Build Bundle(s) / APK(s) > Build APK(s).

जरूरत:
- Android Studio (recent stable)
- JDK 17
- Android SDK 35
- Internet केवल पहली Gradle dependency download के लिए

Package: com.aismarttrader.app
Min Android: Android 6.0 (API 23)
Version: 1.0
